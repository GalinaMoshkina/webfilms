# После титров

Статическая личная фильмотека. Работает без сборки и подходит для GitHub Pages.

## Локальный запуск

Из папки `webfilms`:

```bash
python3 -m http.server 8000
```

Открыть `http://localhost:8000`. Не запускайте сайт двойным кликом по `index.html`:
браузер может блокировать субтитры и видео, открытые через `file://`.

## Публикация на GitHub Pages

1. Создайте отдельный репозиторий и загрузите файлы сайта.
2. Не добавляйте MP4: они исключены через `.gitignore`.
3. Русская версия «Криминального чтива», «Бешеные псы» и «Канк на Земле»
   подключены через встроенные VK-плееры и не требуют загрузки MP4.
4. Для английской версии с локальными `.vtt` всё ещё нужен прямой HTTPS-адрес
   видео из хранилища, поддерживающего CORS и byte-range requests. Страница
   другого сайта не подходит: её плеер нельзя синхронизировать с нашими
   субтитрами из-за same-origin policy.
5. В GitHub откройте **Settings → Pages**, выберите **Deploy from a branch**,
   ветку `main` и папку `/ (root)`.

Навигация сделана через hash (`#/watch/...`), поэтому она работает на GitHub
Pages без дополнительных rewrite-правил.

## Контент

Карточки, описания и личные подписи находятся в `app.js`, в массиве `library`.
Субтитры для английской версии «Криминального чтива» подключены из:

`films/Криминальное чтиво/subtitles-ru.vtt`

Чтобы включить нижний музыкальный плеер, положите файл в
`media/music/theme.mp3` или укажите внешний адрес в `media-config.js`.
