# После титров

Статическая личная фильмотека. Работает без сборки и подходит для GitHub Pages.

## Локальный запуск

Из папки `webfilms`:

```bash
python3 -m http.server 8000
```

Открыть `http://localhost:8000`. Не запускайте сайт двойным кликом по `index.html`:
браузер может блокировать субтитры и видео, открытые через `file://`.

## Публикация на GitHub Pages

1. Создайте отдельный репозиторий и загрузите файлы сайта.
2. Не добавляйте MP4: они исключены через `.gitignore`.
3. Все онлайн-версии подключены через экспортные VK-плееры с `hash` и не
   требуют загрузки MP4.
4. Внешние страницы, для которых не было экспортного iframe, открываются в
   новой вкладке. Подключить к чужому iframe локальный файл субтитров нельзя:
   браузер не даёт синхронизировать два разных домена.
5. В GitHub откройте **Settings → Pages**, выберите **Deploy from a branch**,
   ветку `main` и папку `/ (root)`.

Навигация сделана через hash (`#/watch/...`), поэтому она работает на GitHub
Pages без дополнительных rewrite-правил.

## Контент

Карточки, описания и личные подписи находятся в `app.js`, в массиве `library`.

Общий плейлист находится в `general_music` и перечислен в `media-config.js`.
Музыка конкретного фильма лежит в его папке и подключается в поле `music`
соответствующей карточки. Если своей музыки у фильма пока нет, на его странице
продолжает использоваться общий плейлист.

Поиск работает по русскому и английскому названию, году и типу контента.
